1. Установка инструментов и Boost

	# Обновляем списки пакетов
	
		sudo apt update

	# Устанавливаем компилятор, CMake и библиотеки Boost
	
		sudo apt install build-essential cmake libboost-system-dev libboost-thread-dev

	(#Этого достаточно, чтобы find_package(Boost) в твоем CMakeLists.txt сработал.)

2. Подготовка порта (Права доступа). В Linux доступ к USB-портам (/dev/ttyACM0) по умолчанию закрыт для обычного пользователя. Нужно добавить себя в группу dialout:

	sudo usermod -a -G dialout $USER

	(#Важно: Чтобы изменения вступили в силу, нужно выйти из системы и зайти снова (или перезагрузиться).)

3. Сборка проекта (современный стандарт)

	# Создаем папку для сборки и конфигурируем проект
		
		cmake -B build 			(Создает папку build (если её нет) и сразу запускает в ней конфигурацию)

	# Запускаем компиляцию
	
		cmake --build build 	(Запускает процесс компиляции)

4. Сборка проекта (старый способ)

	# Создаём папку build и переходим в неё

		mkdir build && cd build

	# Собираем проект

		cmake ..
		make

	# Запускаем
	
		./project_name
