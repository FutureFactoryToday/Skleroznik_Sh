Если у вашего пользователя нет прав администратора.
Если при установке вы, скорее всего, ввели пароль для «суперпользователя» (root).

1. Переключитесь на пользователя rootВведите команду:

	su -

	#(Система попросит пароль. Введите тот самый пароль root, который вы придумали при установке. Символы при вводе не будут видны).

2. Установите пакет sudo (на всякий случай). Когда увидите, что в начале строки появился символ # вместо $, введите:

	apt update && apt install sudo 

3. Добавьте себя в группу администраторовВведите команду (замените alex на ваше имя пользователя, если оно другое):

	usermod -aG sudo alex 		(alex - имя пользователя)

	#или

	usermod -aG sudo $USER 		($USER - системная переменная)

4. Примените изменения. Чтобы права заработали, нужно выйти из системы и зайти снова:

	exit

	#Затем в меню (справа вверху или слева внизу) выберите Log Out (Выйти) и войдите обратно. Выполните выход из учётной записи самой операционной системы.
