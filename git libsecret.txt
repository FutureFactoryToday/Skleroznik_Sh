Для хранения паролей выплнить следующие действия:
1) sudo apt install libsecret-1-0 libsecret-1-dev    -    устанавливаемтбиблиотеку.
2) cd /usr/share/doc/git/contrib/credential/libsecret      -      переходим в каталог
3) sudo make     -      переходим в каталог
4) git config --global credential.helper /usr/share/doc/git/contrib/credential/libsecret/git-credential-libsecret     -      включаем в git
