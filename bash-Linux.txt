"clear"				-			очистка терминала

Навигация			pwd(path work directory) 		-	показывает в какой находимся директории
				cd .. (change directory)		-	смена директории на шаг назад
				cd ../.. (change directory)		-	смена директории на n шагов назад
				cd ./path (change directory)		-	относительный путь
				cd /path				-	абсолютный путь

				ls (list)				-	показывает каталоги и файлы в директории
				ls -l (list line)			-	показывает списком вертикальным (таблицей)
				ls -la (list line advanced)		-	показывает таблицу и скрытые файлы
				ls -lt (list line time)			-	упорядочить по времени
				ls -lta (list line time advanced)	-	упорядочить по времени со скрытыми файлами

				man ls (manual)				-	мануал по ls
				man pwd (manual)			-	мануал по cd
				и тд… (но не для всех)


Выход 				q					-	выход



Диспетчер задач и мониторинг процессов					-	top - открыть, q - закрыть
									-	htop - продвинутый top устанавливается отдельно


Запуск программы/процесса	./имя_программы				-	Запуск процесса по относительному пути
				/home/bla-bla/bla-bla-bla/имя_программы	-	Запуск процесса по абсолютному пути
				./имя_программы&			-	Запуск процесса в фоновом режиме

Остановка программы/процесса	sudo kill -9 "PID"			-	Остановка процесса по PIDу
				sudo killall -9 "имя_программы"		-	Остановка процесса по имени



Сети				ip a					-	Показывает сетевые интерфейсы






Поиск директорий и файлов	find -name "имя"			-	Поиск по имени папки и файла
				find -name "имя" > "имя файла"		-	Поиск и запись пути в файл с затиранием 
				find -name "имя" >> "имя файла"		-	Поиск и запись пути в файл с дополнением 

Вывод текстовых файлов		cat "имя_файла"				- 	вывод в консоль содержимого любого файла
				head "имя_файла"			-	вывод в консоль начала содержимого любого файла (10 строк по умолчанию)
				tail "имя_файла"			-	вывод в консоль конца содержимого любого файла (10 строк по умолчанию)
				tail -n "имя_файла"			-	вывод в консоль конца содержимого любого файла (10 строк по умолчанию), где n-необходимое количество строк для вывода
				tail -f "имя_файла"			-	вывод в консоль конца содержимого любого файла (10 строк по умолчанию) в режиме реального времени
