1. Подготовка системных библиотек (В новых дистрибутивах (Ubuntu 24.04+) важно использовать версию 4.1 движка WebKit.)

    sudo apt update
    sudo apt install libwebkit2gtk-4.1-dev \
        build-essential \
        curl \
        wget \
        file \
        libssl-dev \
        libgtk-3-dev \
        libayatana-appindicator3-dev \
        librsvg2-dev -y

2. Установка Rust (через Snap — самый надежный путь для Linux. Как мы выяснили, стандартный apt дает слишком старую версию. Используем Snap для получения актуального компилятора)

    sudo apt install snap -y        #пробуем установить snap, если после этого "sudo snap install rustup --classic" не даёт результата делаем "sudo apt remove snap -y"

    # устанавливаем через snapd
    sudo apt update
    sudo apt install snapd -y

    sudo snap install rustup --classic

    #для 
    rustup default stable
    
    # Создаем ссылки, чтобы система всегда видела Rust
    
    sudo ln -s /snap/bin/rustc /usr/bin/rustc
    sudo ln -s /snap/bin/cargo /usr/bin/cargo

3. Устанавливаем nodejs

    sudo snap install node --classic --channel=20/stable
    node -v


    3.1.(опционально) Универсальный способ поставить самую актуальную версию
        Самым «профессиональным» и универсальным способом в мире веб-разработки считается NVM (Node Version Manager). Он работает на любом дистрибутиве Linux, macOS и даже в WSL на Windows.
        Почему это лучше Snap или Apt:
        -Вы можете установить любую версию (хоть самую новую, хоть десятилетнюю) одной командой.
        -Вам не нужен sudo для установки библиотек через npm install -g.
        -Вы можете переключаться между версиями для разных проектов.
        
        Как установить NVM:

        3.1.1 Запустите скрипт установки:
        
            curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
        
        3.1.2 Обновите окружение (или просто перезапустите терминал):
        
            source ~/.bashrc
        
        3.1.3 Установите самую последнюю (Latest) версию:
        
            nvm install node  # Установит самую-самую свежую
            nvm use node      # Начнет её использовать
        
            #Или установите стабильную (LTS), если нужна надежность: 

            nvm install --lts

4. Создание проекта

    npm create tauri-app@latest
    # Выбираем: React -> TypeScript -> Vite

    4.1(опционально) Клонируем с github и заходим в папку

        git clone https://github.com
        cd название-проекта

        4.1.1 Для фронтенда (React/Vue):

            npm install


5. Запуск в режиме разработки. Теперь можно запустить проект, чтобы увидеть его в окне:

        npm run tauri dev

6. Установка сборщика иконок (один раз) Tauri нужно сгенерировать иконки всех размеров из одной картинки.

    npm install -D @tauri-apps/cli

7. Запуск сборки

    npm run tauri build

    Что произойдет в этот момент:
    Vite скомпилирует ваш React-код, минифицирует его и уберет всё лишнее.
    Rust скачает все зависимости и скомпилирует бинарный файл с максимальной оптимизацией (флаг --release).
    Tauri упакует всё это в системные пакеты.
    Где искать готовый файл?
    После завершения (это может занять до 10 минут) ищите результат здесь:
    src-tauri/target/release/bundle/
    Там вы найдете:
    .deb — установочный пакет для Ubuntu/Debian/Armbian.
    AppImage — универсальный файл, который запускается двойным кликом без установки (самый удобный формат).
