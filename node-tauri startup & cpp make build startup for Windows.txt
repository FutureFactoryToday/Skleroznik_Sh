#############		tauri + React 		################
################################################################

1) Скачать Visual Studio Build Tools:

	1.1) Зайти на сайт Microsoft по адресу: https://visualstudio.microsoft.com/downloads/
	1.2) Найти "Build Tools для Visual Studio 2022"
	1.3) Скачать, обычно это файл "vs_buildtools.exe"

2) Запусть его — откроется Visual Studio Installer;

3) Выбрать пакет "Разработка классических приложений на C++", и в правой колонке (Сведения об установке) убедиться, что выбраны следующие пункты:

	3.1) MSVC v143 — VS 2022 C++ x64/x86 build tools (сам компилятор);
	3.2) Windows 10 SDK или Windows 11 SDK (библиотеки системы);
	3.3) C++ CMake tools для Windows (Tauri может их потребовать);

4) Нажать кнопку «Установить» (понадобится около 5-7 ГБ места);

5) Установить WebView2 с официального сайта Microsoft:

	5.1) В Windows 10/11 он обычно уже есть. 
	5.2) Если нет — скачай "Evergreen Bootstrapper" с сайта Microsoft.

6) Установить Rust с сайта rustup.rs. скачай rustup-init.exe и выбери вариант по умолчанию "1" (Варианты выбора появятся во время установки в открытом терминале);

7) Установить (если нету VS code).

8) Открыть VS Code, нажать Ctrl+Shift+X (Extensions) и установить:

	8.1) rust-analyzer — даст тебе подсказки, переходы по коду и проверку ошибок для Rust;
	8.2) Tauri — официальное расширение для поддержки конфигурационных файлов Tauri;
	8.3) ESLint / Prettier — для красоты и чистоты твоего TypeScript кода;
	8.4) Перезагрузить VS code;

9) Открыть VS code и нажать (Ctrl + `) чтобы открыть терминал. Все дальнейшие процедуры выполнять в этом терминале:

	9.1) Проверь Rust: Введи rustc --version. Если выдает ошибку — значит, rustup-init.exe (из предыдущего шага) 	всё же нужно запустить один раз, чтобы установить компилятор в систему.
	9.2) Проверь Node.js: Введи npm --version 

	##### Если версия node.js устаревшая, а так скорее всего и будет, выполнить установку свежей версии #####

	9.3) Перейди на официальный сайт nodejs.org.
	9.4) Выбрать версию LTS (сейчас это 22.x.x и выше). Она самая стабильная.
	9.5) Скачать установщик .msi и просто запусти его. Он сам обновит старую версию.
	9.6) Перезапусти VS Code;
	9.7) После установки Node.js обязательно полностью закрыть и снова открыть VS Code. Это нужно, чтобы терминал 	подхватил новую версию.

10) В терминале VS code выполнить проверку node.js:

	node -v

11) Дать разрешения на выполнение скриптов для текущего пользователя:

	Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

12) Перейти в корневую папку проекта где лежит файл package.json (проект в корневой папке можно либо создать командой "npm create tauri-app@latest
", либо сделать clone имеющегося проекта с github) и выполнить установку зависимостей:

	npm install

13) Выполняем запуск проекта в режиме отладки:

	npm run tauri dev

14) Выполняем сборку проекта в исполняемый файл:

	npm run tauri build		- исполняемый файл будет лежать project-name/target/release/bundle/msi/


################################################################
#############		c++ + make 		################
################################################################


1) Открыть терминал в VS Code и выполни эти команды (это скачает vcpkg, установит его и соберет Boost):

	# 1. Клонируем менеджер пакетов в корень диска C (или в любое удобное место)

	cd C:\
	git clone https://github.com/Microsoft/vcpkg.git
	cd vcpkg
	.\bootstrap-vcpkg.bat

2) Устанавливаем Boost:

	# 2. Устанавливаем Boost (это может занять время, он будет компилироваться)

	.\vcpkg.exe install boost-asio boost-beast boost-system

3) Открываем VS code (Поскольку ты уже ставил плагины для Tauri, тебе нужно только одно расширение: CMake Tools);

	3.1) Нажми Ctrl+Shift+P и введи: "CMake: Configure";
	3.2) Когда VS Code спросит про "Kit", выбрать: "Visual Studio Community 2022 Release - amd64";
	3.3) Открыть Параметры в VS Code Ctrl + ,
	3.4) В поиске вверху ввести: cmake.configureSettings;
	3.5) Нажать на синюю ссылку «Edit in settings.json»;
	3.6) В открывшемся файле заменить содержимое на:

		{
    			"workbench.colorTheme": "Dark Modern",
    			"cmake.configureSettings": {
        			"CMAKE_TOOLCHAIN_FILE": "C:/vcpkg/scripts/buildsystems/vcpkg.cmake"
    			}
		}

	3.7) Нажать в нижней панели VS Code кнопку [Build].
	3.8) Если не сработает автоматически — нажми Ctrl+Shift+P, введи CMake: Delete Cache and Reconfigure и нажми 	Enter.
	3.9) Снова нажать в нижней панели VS Code кнопку [Build].

Что произойдет дальше:

1) Начнется компиляция твоего main.cpp.
2) Линковщик соберет всё воедино вместе с Boost.
3) В папке проекта появится новая папка build, а внутри неё (скорее всего в Debug или Release) — твой готовый файл nc_bridge_cpp.exe.
4) Где искать готовый файл?
5) После того как полоска прогресса дойдет до 100%, загляни сюда:
C:\Projects\nc-bridge-cpp\build\Debug\nc_bridge_cpp.exe (путь может немного отличаться, если ты выбрал Release).
